    - R8 规则在历史 {T1, T2} 上确实再给出 T2 的尺寸；
    - 改用顺序割线（代码里已有的 `force_sequential=True`。计划 R9 给 D1c、D3c 用过，两者第一次（T4）就落进当时的可用窗：中央谷 6.72、6.75 GHz，|D| 0.31、0.21 dB），给出新的 **T4：Ws 0.630、Lm 6.526、Ls1 12.839、Ls2 1.810、Ls3 2.430**。预测中央谷 6.740 GHz、D −0.02 dB、均值 −22.80 dB，两峰都在窗内；
    - 把 T3 也放进历史，结果不变。
  - **T4 有多可靠。**
    - T4 的步长有 77% 沿 T1→T2 方向，这个方向上的割线是实测的。
    - 另外有 0.004 mm 的正交分量，这部分贡献 D +0.33 dB，仍靠 B1 的雅可比估。这部分如果偏 50%，D 会偏 ±0.17 dB，还在 ±0.2 以内。
    - 我估计 T4 一次调准的把握约一半，三次以内调准的把握较大。
- **带宽梯度可以用。** 把 B1 的实测半差换到调参坐标（Lm、Lc、Ws），预测 T1→T2 的 BW20 变化 −6.1 MHz，实测 −7.7 MHz。用同样的梯度，T4 的 BW20 约 6.579 GHz。
- **W5R 的保证带估计约 3.29–9.55 GHz，宽 6.26 GHz，比 W4R 宽约 0.24 GHz。** 算法是 T4 的预测名义带边加上 W4R 实测的带边移动。

### 1.1 到目前为止的规律

1. **同一个 Wm 下，带宽只由稳健目标决定。** 三个调参量（Lm、Lc、Ws）恰好定住三个目标（中央谷、D、两峰均值），没有剩余自由度。
   - 在“中央谷和 D 不变”的调准曲面上，两峰每变浅 1 dB，BW20 增加 117–156 MHz（分别用 W5R 割线更新后的雅可比和 B1 的雅可比算）。
   - 实测的 W4 → W4R 是 164 MHz/dB，B1 → B1R 是 178 MHz/dB。
2. **Wm 本身几乎不改带宽，它先把两峰压深，再由 Ws 换成带宽。**
   - 在 B1 上，Wm +0.02 mm 只让 BW20 变 +2.6 MHz，但两峰均值深 0.18 dB；Ws +0.02 mm 让 BW20 宽 58 MHz。
   - 把两步合起来算，Wm 每加宽 0.15 mm，带宽约增加 0.18–0.23 GHz。实际看到的是：
     - 名义调准下每 0.15 mm 宽 0.14–0.17 GHz（R16 记录的 0.9–1.1 GHz/mm）；
     - 稳健目标下 W4R → W5R 预计宽 0.16–0.19 GHz。W4R 换算到同一目标约 6.39–6.42 GHz；W5R 的 T1、T2 用带宽梯度推到 T4，都是 6.578–6.580 GHz。

     量级一致，估算偏高两成左右。
   - 所以平台会出现在“Wm 压深两峰的效果变弱”的地方。
3. **角点 Δ|Γ| 随 Wm 加宽下降**：0.0268 → 0.0233 → 0.0221。
4. **角点的带边移动可以相加，也能跨宽度迁移**（见上面两条）。
5. **网格偏差稳定**：中央谷下移 20–40 MHz；W4R 的带边移动 +7 / +20 MHz。

## 2. 为什么做阶段 9

- **W5R 只差一步。** T1、T2 已经夹住目标，修好调参器后 T4 大概率调准。修调参器是离线的，不花求解。
- **平台还没出现。** 稳健目标下 W4R → W5R 预计每 0.15 mm 宽 0.16–0.19 GHz（约 1.1–1.2 GHz/mm），不比 R16 记录的名义调准斜率（0.9–1.1 GHz/mm）小。W6R、W7R 两个点能看出曲线有没有开始弯。
- **交付件可以更宽。** 按第 1.1 节第 2 条，W6R、W7R 的保证带可能各再宽 0.15 GHz 左右。9D 只在最后选定的那一版上补做 C2、C3 和密网格，不在中间宽度上花。
- **带边迁移需要前瞻检验。** 第 1 节的迁移证据是事后发现的。9D 在新宽度上先登记预测、再仿真；通过的话，以后估算保证带只要做 C1。

## 3. 方案

### 3.1 9A：R9 调参器（离线，求解前必须通过）

1. **更新规则改为顺序割线。**
   - 同一宽度上，按求解顺序，每两次相邻的试验之间做一次完整的 Broyden 秩一更新，三行（中央谷、D、均值）都更新；dx = 0 的跳过。
   - 这就是现有代码的 `force_sequential=True`。阶段 9 不再用 R8 的选择性触发。
2. **雅可比可以继承。** 给 `propose_history` 加一个雅可比初值参数：
   - W5R 从 B1 的 J0 开始，叠加 W5R 的全部割线（与回放相同）；
   - W6R 的初值取 W5R 最后的雅可比，W7R 的初值取 W6R 最后的雅可比。

   每个宽度的初值，在该宽度的 T1 求解前写进冻结附录。
3. **提交前查重。**
   - 指纹由 geometry_mm（取到 0.001 mm）、cad_ir、网格、求解和扫频设置组成，不含案例名、序号、时间戳和调参记录。
   - 与 R1–R9 所有已完成的案例比对。相同就不提交、不计费，该宽度停止调参，标为 `controller_stalled`，然后继续下一个独立步骤。
4. **中央谷验收窗放宽到 6.73–6.76 GHz，调参目标仍是 6.74。**
   - 理由：三次密网格的中央谷下移 20、30、40 MHz。名义放在 6.73–6.76 时，密网格落在 6.69–6.74，仍在 6.72 ± 0.03 之内。
   - 其他验收条件不变：两峰都在 [P_req − 0.2, P_req]，|D| ≤ 0.2 dB，S21 ≥ −2 dB。
   - 所有宽度都用同一个 P_req（−22.695 dB），带宽才可以直接比较。
   - 交付误差的中央谷项相应改为“到 6.73–6.76 窗口的距离 ÷ 0.01”，D 项和两峰项不变。这样 T1 的基点误差从 3.00 变为 2.31，T2 仍是 3.51，T1 仍是基点，T4 不变。
5. **回放测试。** 离线，放在 R9 目录里，并接进本阶段的默认验证：

   | 编号 | 内容 | 期望 |
   |---|---|---|
   | R9-1 | R8 规则，历史 {T1, T2} | 给出 T2 的尺寸（记录缺陷） |
   | R9-2 | R9 规则，历史 {T1, T2} | 基点 T1；T4 = Wm 2.80、Ws 0.630、Lm 6.526、Ls1 12.839、Ls2 1.810、Ls3 2.430；预测 y = [6.7404, −0.0190, −22.8001]，差 ≤ 1×10⁻⁴ |
   | R9-3 | R9 规则，历史 {T1, T2, T3} | 与 R9-2 相同 |
   | R9-4 | 查重 | 与 T2 指纹相同的提议被拒，不计费 |
   | R9-5 | 雅可比继承 | 给了初值就用给定值，不用 J0 |

   任何一项不通过，就停下报告，不启动求解。

### 3.2 9B：W5R 调准

- 目标和约束照第 3.1 节第 4 条。
- **T4 必须等于 R9-2 的输出。** T5、T6 由 R9 用 W5R 的全部历史给出，最多 3 次。
- 调准的那一次记为 **W5R\***。
- 到 T6 仍没调准，本阶段停止，不做 9C、9D，写报告。

### 3.3 9C：Wm 扫描（W6R、W7R）

1. **W6R（Wm 2.95）**，只在 W5R 调准时做。
   - **T1 用调准路径线性外推**，在调参坐标（Lm、Lc、Ws）中计算：
     1. 把 W4R 和 W5R\* 都用 W5R 最后的雅可比换算到准确的目标：W′ = W + 解(Jᵀ, 目标 − y(W))，y 用各自的实测值。W4R 调的是旧目标（两峰均值 −23.24 dB），这一步把它换到 −22.80 dB。
     2. W6R T1 = 2·W5R′ − W4R′，Wm 改为 2.95，取整到 0.001 mm，Ls2、Ls3 按跟随规则重算。这一步不受步长上限约束。
     3. 预测的 y 就是目标。T1 实测偏离目标多少，就检验了“调准尺寸随 Wm 线性变化”这条规律。

     为什么不再用 R16 的固定宽度步（Ws +0.069、Lm −0.029、Ls1 +0.100）：那是名义调准下 W3 → W4 的改动。用在 W5R T1 上，留下了中央谷 −0.03 GHz、两峰均值 +0.19 dB 的偏差。新规则用的是同一稳健目标下实测的调准路径；按这条路径，每 0.15 mm 的 Lc 改动约 +0.217 mm，固定宽度步是 +0.238 mm。

     如果 W5R\* 就是 T4 且正好落在预测上，W6R T1 约为 Ws 0.704、Lm 6.494、Ls1 12.907、Ls2 1.958、Ls3 2.504（改用 B1 的 J0 换算，相差 ≤ 0.006 mm）。它和下面 W7R 的参考尺寸都通过了现有的几何预检。计算见 `review_s8.py` 的 `width_extrapolation`。
   - 最多 3 次，雅可比初值取 W5R 最后的。
   - T1 过不了几何门禁就跳过 W6R，不找替代点，9C 停止。
   - 3 次没调准：不做 C1W6 和 W7R，直接进 9D。
   - 调准后做 **C1W6**：e +0.01、εr 3.50、h0 − tol_h，加在 W6R\* 上。
2. **W7R（Wm 3.10）**，下面三条都满足才做：
   - W6R 调准；
   - C1W6 稳健：Γ 加网格偏差 ≤ 0.1，网格偏差借用 0.002336；
   - BW20(W6R\*) − BW20(W5R\*) ≥ 0.05 GHz。

   做法：
   - **T1** = 2·W6R′ − W5R′，Wm 改为 3.10。W6R′ 用 W6R 最后的雅可比换算，W5R′ 沿用第 1 条的值。如果 W5R\*、W6R\* 都正好落在上面的参考尺寸，W7R T1 约为 Ws 0.778、Lm 6.462、Ls1 12.976、Ls2 2.106、Ls3 2.578。
   - 最多 3 次，雅可比初值取 W6R 最后的。过不了几何门禁就跳过，不找替代点。
   - 调准后做 **C1W7**；3 次没调准就不做 C1W7，直接进 9D。
3. 每个宽度都报告：调准尺寸、BW20、两端带边、C1 的 Δ|Γ| 和带边移动，以及每次试验的预测与实测。

### 3.4 9D：选定交付件，补全保证带

1. **选定。**
   - 候选是 W4R，以及 9B、9C 中调准、且 C1 稳健的设计。W5R\* 先用 T1 上的 C1W5 作为候选资格。
   - 选估算保证带最宽的一个。估算方法：名义带边分别叠加四组带边移动，再取交集。
     - C1 用该宽度自己实测的移动；
     - C2、C3、密网格用 W4R 实测的移动。
   - 选中 W4R 时，9D 不做（W4R 已经有完整的五曲线）。
   - 选中 W5R\* 时，先在 W5R\* 上补做 C1。
   - 选定结果和预测带边，要在 9D 求解前写进冻结附录并提交。
2. **在选中的设计上做 C2、C3 和密网格：**
   - C2：e −0.01、εr 3.60、h0 + tol_h；
   - C3：e −0.01、εr 3.50、h0 + tol_h；
   - 密网格照 R15 第 3.3 节。
3. **报告**该设计的五曲线保证带（名义、密网格、C1、C2、C3 的交集），以及带边的预测与实测（Q40）。
