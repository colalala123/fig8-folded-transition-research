## 2. 修改

### 2.1 −20 dB 带宽改按主通带判断（取代 R1 的 3.6 节相关句）

R1 写的是“BW20 的连通分量多于 1 时记为空”。按整个扫频范围 0.01–15 GHz 数分量，会把 14.9–15.0 GHz 扫频边缘的一小段也算进去。

新定义，对 −15 dB、−20 dB 和联合带宽都适用：

1. 主通带是 |S11| 低于门限、并且包含中央谷频率的那个连通频段。
2. 主通带同时包含两个内峰的频率时，带宽有效，取主通带的宽度。
3. 主通带不含两个内峰，或者找不到两个内峰，带宽记为空，原因写“主通带在内峰处断开”。外包络仍另存一栏，不参与拟合。
4. 主通带以外的其他连通段记入 `secondary_components`，不影响有效性。
5. 主通带碰到扫频上下限时，照旧标记 `edge_censored`。

对归档的 80 条曲线复核：

| | R1 字面规则 | 主通带规则 |
|---|---:|---:|
| −20 dB 带宽有效 | 20 | 27 |
| 在内峰处断开 | 60（含 7 条误判） | 53 |

- 被误判的 7 条：N04_A18、N10_A18、N10_A18_M、N10_A18_S、N11_A18_S、N17_A18_C1、N21_A18。它们的内峰都不高于 −20 dB，只是在 14.9–15.0 GHz 多出一小段。
- 新规则下，有效的 27 条内峰全部不高于 −20 dB，断开的 53 条内峰全部高于 −20 dB，两种判断一致。
- 有效的 27 条，−20 dB 带宽在 5.726–6.002 GHz 之间，平均 5.858 GHz。其中 a = 1.4 mm 有 12 条，a = 1.8 mm 有 15 条。

这是回顾性的描述，不是规律。

### 2.2 提取不唯一改按不同参数盆地判断（取代 R1 的 3.7 节相关句）

R1 写的是“次优解的代价在最优解的 1.05 倍以内时标记”。两个起点收敛到同一个极小值时也会触发，80 条全部被标记，参数差只有 4×10⁻⁸。

新定义：

1. 一个收敛的起点，四个参数（z′m、z′s、fm、fs）里任一个与最优解的相对差超过 1%，才算另一个解。
2. 存在另一个解，并且它的代价不超过最优解的 1.05 倍，标记“提取不唯一”。
3. 起点之间必须相互独立。R1 实现里第二个起点用的是第一次拟合的收敛结果，可以保留作精修，但不计入起点数，独立起点仍不少于 5 个。
4. 每条记录保留所有起点的代价、参数和所属的解。

复核：80 条都存在别的解，但别的解的代价最少是最优解的 2.96 倍。按新定义，80 条里 0 条不唯一。

### 2.3 每一次尝试都要重新做净距筛选（补充 R1 的 3.1 节）

登记表里的筛选只针对初值。调参会改变 Ls1，端头位置随之移动。

阶段 3 的 `S3_EQ_N04_04`（a = 3.0 mm）初值余量很小：端头到中央线边缘 0.8153 mm（下限 0.813），两个端头之间 3.567 mm（下限 3.562）。

规则：

1. 每次提交求解前，用当次的几何重新筛选。不通过的几何不提交。
2. 不通过是由调参引起时，把 a 减小到能通过的最大值（步进 0.001 mm），其他调参量不变。记录名义 a 和实际 a，分析用实际 a。
3. 这次调整不另算一次尝试，但要在记录里写明。

两个端头不得相接的要求不变。

### 2.4 测试 11 的浮点比较

`test_11_registry_regeneration` 用的是完全相等。审核方环境（Linux，Python 3.13）里重新生成的登记表与冻结版本有 3.8×10⁻¹⁵ 的相对差，结构差异为 0，记录数 79。这是测试的可移植性问题，登记表内容没有问题。

新目录里的对应测试改为：字符串、整数、布尔值和结构完全相等；浮点数相对差不超过 10⁻⁹、绝对差不超过 10⁻¹²。R1 目录里的原测试不改，在 R2 报告里注明这一条已知问题。
