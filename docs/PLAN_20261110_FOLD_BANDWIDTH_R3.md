## 2. 阶段 3 的纹波目标（取代原计划 6 节阶段 3 和 R1 3.2 节的 −21 dB）

### 2.1 调准的判据

原判据：两个内峰的平均电平为 −21.0 ± 0.15 dB。

新判据，三条同时满足才算调准：

1. 两个内峰都不高于 −20.0 dB。这是硬指标。
2. 两个内峰的平均电平不低于 −20.6 dB。这一条只为了让各个点的纹波接近，便于比较。
3. 中央谷 6.72 ± 0.03 GHz、内峰差 ≤ 0.5 dB，与原计划相同。

初值按平均内峰 −20.3 dB 反解 Ws。每个设计仍最多 3 次。

### 2.2 带宽要换算到同一纹波

按规律链的先验，内峰每升高 1 dB，−20 dB 带宽增加约 150 MHz；而折臂从 0 加到 2.9 mm，等纹波带宽的先验变化只有约 90 MHz。纹波相差 0.3 dB 就有约 45 MHz，与要测的量同一量级。

所以每个调准点同时报告两个值：

- 实际的 BW20。
- 换算到平均内峰 −20.3 dB 的 BW20。换算斜率用阶段 3 自己的数据拟合（同一基准内 BW20 对平均内峰回归），拟合不出来时用先验 150 MHz/dB，并注明用的是哪一个。

阶段 3 的结论以换算后的值为准，两个值都留在表里。

### 2.3 最长的一档从 3.0 mm 改为 2.9 mm

纹波目标放宽后，所需的 Ws 变宽约 0.02–0.03 mm，折臂端头向中央微带线靠近。N04 的 a = 3.0 mm 初值，端头到中央线边缘只有 0.798 mm，小于下限 0.813 mm，不能提交。

两个基准的最长一档都改为 a = 2.9 mm。端头到中央线边缘 0.975 mm（N04）和 1.033 mm（N14），调参还有余量。

新的阶梯：a = 0、0.6、1.4、2.2、2.9 mm，g = 0.55 mm 不变。

## 4. 周报 4 个点的核对

### 4.1 问题

07-25 周报的 4 个弯折点：折臂加长 0.6 mm，R_eff 从 0.825 升到 0.910，−2 dB 带宽从 7.16 降到 6.92 GHz，约 240 MHz。本仓库同样线宽的 24 对里，折臂加长 0.4 mm，−2 dB 带宽平均只变 −1.7 MHz。原计划 4.4 节把这记为“对不上”。

### 4.2 离线核对的结果

用归档的 80 条曲线，只比较相对变化，因为两边 R 的取法不同。

| 比较 | R 的相对变化 | −2 dB 带宽的变化 |
|---|---:|---:|
| 周报的 4 个点（折臂 +0.6 mm） | +9.8% | −240 MHz |
| 本仓库，线宽固定，折臂 +0.4 mm（24 对） | +2.3% | −1.7 MHz（−7.7 到 +5.2） |
| 同上，按比例放大到 +0.6 mm | +3.4% | −2.6 MHz |
| 本仓库，折臂固定，线宽不同（a = 1.4 的 40 条） | 按 +9.8% 折算 | −200 到 −209 MHz |
| 本仓库，折臂固定，线宽不同（a = 1.8 的 40 条） | 按 +9.8% 折算 | −185 到 −191 MHz |

最后两行的范围对应 R 的两种取法（名义阻抗比、电路拟合值）。带宽与 ln R 的相关系数在 −0.81 到 −0.90 之间。

三点结论：

1. 线宽固定时，折臂加长 0.6 mm 只能让 R 升高约 3.4%，是周报里 9.8% 的三分之一左右。周报那 4 个点的 R 变化，大部分不是折臂造成的。
2. 靠改线宽让 R 升高 9.8%，本仓库的数据里 −2 dB 带宽会减少约 190–210 MHz，与周报的 240 MHz 同一量级。
3. 归档记录 `archive/fig8_resume_20261007/均匀与弯折PR口径核验.md` 写明：早期弯折种子的 P_eff、R_eff 是从均匀模型的种子复制过来的标签，不是从弯折曲线提取的。周报的 R_eff 很可能就是这种标签，4 个点对应 4 个不同的阻抗目标，线宽各不相同。

所以这两处并不矛盾。周报的 4 个点同时改了折臂和阻抗目标，带宽下降主要跟着阻抗比走；本仓库的配对只改折臂。用户的判断与数据一致。

### 4.3 这次核对的限度

- 这是回顾性的推断。周报 4 个点的线宽、基板和曲线不在本仓库，没有直接核对。
- 本仓库 R 的变化范围只有约 10%，周报的变化正好跨过整个范围。
- 本仓库只有 a = 1.4 和 1.8 两档。“线宽固定时折臂对 −2 dB 带宽几乎没有影响”在 0 到 2.9 mm 的整个范围内是否成立，还没有数据。

### 4.4 还要做的验证

阶段 2 的阶梯（批次 2a、2b）线宽严格不变，a 从 0 到 3.0 mm，直接检验第三条限度。假设 H3 的判据不变：|ΔBW_S21| < 0.2·|ΔBW15|。
