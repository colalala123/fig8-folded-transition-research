## 2. 新数据告诉了我们什么

B1 T2 基准：中央谷 6.73 GHz，内峰 −20.796 / −20.687 dB，BW20 6.4549 GHz。下表是七组扰动的中心差分（正侧减负侧再除以 2）和最高内峰的最大升幅。

| 来源 | 扰动 | 低峰 dB | 高峰 dB | 中央谷 MHz | 最高内峰最大升幅 dB |
|---|---|---:|---:|---:|---:|
| Ws | ±0.02 mm | +0.244 | +0.561 | −25 | 0.503 |
| Lm | ±0.02 mm | −0.288 | +0.331 | −35 | 0.234 |
| Ls1 | ±0.02 mm | +0.289 | −0.208 | 0 | 0.313 |
| Wm | ±0.02 mm | −0.229 | −0.128 | −5 | 0.273 |
| 蚀刻 | 每边 ±0.01 mm（P9c / P10） | +0.023 | +0.333 | −5 | 0.353（过蚀刻） |
| εr | ±0.05（P12 / P11） | −0.067 | −0.178 | −35 | 0.130（3.50） |
| **h** | **±0.038 mm（P14 / P13）** | −0.230 | **−1.884** | **+90** | **1.729（0.775）** |

### 2.1 规律

1. **板厚 h 压倒其他所有来源。** h 变薄 0.038 mm，高频内峰从 −20.69 dB 升到 −18.96 dB，完整的 −20 dB 主窗消失；中央谷移动 90 MHz。它的影响是蚀刻的 5 倍、εr 的 13 倍。按 |Γ| 算并计入网格偏差，B1 只能容忍板子变薄约 0.009 mm。
2. **两参数规律在公差尺度上成立。** 对全部 16 个公差点（相对 B1）做拟合：
   - 两内峰的均值变化 ≈ 20.0 × ΔP_eff（dB），R² 0.983，残差 RMS 0.055 dB；
   - 倾斜 D = 高峰 − 低峰的变化 ≈ −0.042 × Δ(fm − fs)（MHz），R² 0.969，残差 RMS 0.12 dB。

   去掉 h 的两个点重新拟合，斜率仍是 20.4 和 −0.042，R² 约 0.95。所以这不是被 h 的大数值拉出来的。

   换句话说，任何一种公差（几何、蚀刻、εr、h）对两内峰的影响，都只经过两个量：P_eff（纹波深度）和 fm − fs（两个谐振的失谐）。这把阶段 1 的“纹波只由 P_eff 决定”推广到了公差尺度，也给出了补偿任何误差的配方：用 Ws 拉回 P_eff，用 Lm、Ls1 拉回失谐和中央谷。
3. **h 不是通过微带阻抗起作用的。** R10 的 Q14 依据是“h −4.7% 相当于 Wm +0.1 mm”。按 Wm 的实测斜率外推，应该是低峰 −1.26、高峰 −0.71 dB；P13 实测是 +0.40、+1.73 dB，符号都反了。数据显示 h 主要改变槽线一侧的变比 N2：
   - N2 每 0.038 mm 变 1.8%，所有平面尺寸 ±0.02 mm 都只让 N2 变 ≤ 0.15%；
   - fm 和 fs 向相反方向移动（各约 ±20 MHz）：微带一侧和槽线一侧对介质厚度的响应相反。

   结论是，h 是一个平面尺寸很难“顺便”抵消的独立自由度。Q14 的预测结果对了，但理由错了，记录在案。
4. **余量应按 |Γ| 叠加，不按 dB。** 公差在反射系数上可加。纹波越深，同样的 Δ|Γ| 对应的 dB 升幅越大。按 |Γ| 算，三项来源是：

   | 来源 | Δ|Γ| |
   |---|---:|
   | 蚀刻 | 0.0038 |
   | εr | 0.0014 |
   | h | 0.0204 |
   | 平方和根 | 0.0208 |

   再扣掉网格偏差 0.256 dB 和调参误差 0.1 dB 对应的 Δ|Γ|，得到 P_req = −22.45 dB。R10 的 dB 口径算出来是 −22.13 dB，低估了深纹波处的需要。P_req 随 h 公差变化：

   | h 公差 | P_req |
   |---|---:|
   | ±0.025 mm | −21.71 dB |
   | ±0.038 mm（默认） | −22.45 dB |
   | ±0.051 mm | −23.28 dB |
   | 实测板厚 ±0.005 mm | −20.79 dB |

### 3.2 取消的项目

- **密网格 P1、P2：取消。**
  - 这项条件的用意是确认普通网格灵敏度不是噪声。但余量 M 只包含蚀刻、εr、h，不含 Ws，所以 P1、P2 的密网格结果不改变任何决定。
  - h 的升幅 1.73 dB 是 N0（0.078 dB）的 22 倍；第 2.1 节的两参数规律在 16 个点上的残差只有 0.05 dB，已经从另一个角度说明普通网格灵敏度自洽。
  - N0 ≤ 0.1 dB，按 R10 不加进 M。
- **B1 上的 C1：取消。** B1 单是 P13 就不满足要求，C1 不改变“B1 不稳健”的结论。真正要回答的“三项同时出现时是否可加”由 C1R 在 B1R 上回答。

### 3.3 P_req 的新口径

- |Γ| = 10^(dB/20)。令 Γ_B 为 B1 最高内峰对应的 |Γ|（−20.687 dB）。
  - 每项来源取两侧中较大的 Δ|Γ|（下限 0）：蚀刻用 P9c / P10，εr 用 P11 / P12，h 用 P13 / P14。
  - h 一项乘以 tol_h / 0.038，按线性缩放；P13、P14 两侧曲率 0.16 dB，近线性。
- Γ_req = 0.1 − √(ΣΔ|Γ|²) − Δ|Γ|_mesh − Δ|Γ|_tune。
  - Δ|Γ|_mesh、Δ|Γ|_tune 分别是 Γ_B 加 0.256 dB、加 0.1 dB 后的 |Γ| 增量。
  - P_req = 20·log10(Γ_req)。默认输入下为 −22.452 dB。
- 冻结时用 `review_s6r3.py` 的数值核对，两边差应 ≤ 0.005 dB。

### 3.4 6B：B1R（稳健交付）

1. **设计约束。** 沿用 R10 第 3.4 节第 3、4 条，只换 P_req：
   - Wm 2.35、a 1.8、g 0.55 不变；
   - 两内峰都在 [P_req − 0.2, P_req]，|D| ≤ 0.2 dB；
   - 中央谷 6.72 ± 0.03 GHz，S21 ≥ −2 dB；
   - 最多 3 次。
2. **T1。** 用第 2.1 节的两参数规律或 J 冻结，两者都要写出来。

   我的参考估计：以 B1 为基准，用 Ws、Lm、Ls1 三组中心差分的线性解，目标两峰 −22.45、中央谷 6.72，得到：
   - Ws ≈ −0.092 mm（约 0.462）；
   - Lm ≈ +0.072 mm（约 6.587）；
   - Ls1 ≈ +0.035 mm（约 12.543）。

   这是 4–5 个步长的外推，只作核对。执行者的 T1 与它任一尺寸相差 > 0.03 mm 时，要在冻结里说明理由。
3. **调准后做两个确认。**
   - 一次密网格；
   - 一次 C1R：在 B1R 上同时加过蚀刻 e = +0.01、εr 3.50、h = h0 − tol_h，普通网格。
4. **判定和标注（如实，二选一或都不满足）。**
   - **“统计稳健（平方和根）”**：密网格两内峰的 |Γ| 都 ≤ 0.1 − √(ΣΔ|Γ|²)。
   - **“最坏角点稳健”**：C1R 的最高内峰加上 B1R 自己的密网格偏差 ≤ −20.0 dB。

   我预计前者满足、后者擦边不满足（Q23）。角点不满足不算失败，照实标注，不加调参。
5. **3 次没调准：** 停下报告，不追加。
6. **h0 改为实测值时：** P13、P14 是在 0.813 上测的灵敏度，直接用于 h0。报告里注明这一点。
