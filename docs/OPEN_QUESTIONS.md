# 尚未完成的研究与建议顺序

**此文件不是仿真执行授权，也不是已经完成的结果。旧整批保持暂停。**

1. **离训练样本更远的新P/R家族验证。** 最新成功点距已测样本约0.00321mm，需预先冻结新家族、预测及评价指标，才能检验泛化；不能把近邻微调都叫独立测试。
2. **带边和中心位置的可靠约束。** 分别评估低/高边、中央谷、内峰及联合连通性；保留假通过，建立数据支持的安全裕量，而非任意加常数就声称稳健。
3. **明确逆向设计的可行域。** 当前公式和搜索用于既定材料、间隔、折臂和5.6GHz主窗，尚无任意带宽/S11目标都能输出可用解的保证。无候选不等于物理不可达。
4. **将有信息量的失败点保留进训练/可行性研究。** 不必以“48点全部调到通过”为科学目标；若改变P/R去凑达标，必须记录坐标变化，不能继续称固定P/R比较。
5. **数值与制造稳健性。** 对最终要交付的设计，按独立计划验证直接频点、网格变化和制造偏差。最新单例未完成这些验证。
6. **弯折物理解释。** 需要合理的直槽对照与辐射/导体/介质损耗分解，才能检验减辐射与本征带宽假设。当前仅有S参数经验趋势。
7. **工程可移植性。** 通用hook需新电脑实测；历史专用脚本仍依赖本机路径和控制环境，不能靠复制即运行。归档中的离线预测已单独移植，不启动任何仿真。

建议下一次有限实验优先围绕1和2，而不是重复重跑已经闭账的案例。补点数量、资源、验收和停止条件应在新授权后单独冻结。
