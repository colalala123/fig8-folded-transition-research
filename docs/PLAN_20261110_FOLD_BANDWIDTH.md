## 1. 要解决的问题

研究对象是论文 Fig. 8 的折叠槽线微带-微带垂直过渡（Yang 等，IEEE TMTT 2017，65 卷 8 期，“Analysis and Design of Wideband Microstrip-to-Microstrip Equal Ripple Vertical Transitions and Their Application to Bandpass Filters”）。论文 PDF 不在仓库里，由用户另行提供。

用户要做三件事，按优先级排列：

| 编号 | 目标 | 完成的标志 |
|---|---|---|
| G1 | **弯折情况与带宽之间的量化关系**（本计划的重点） | 给出公式：折臂长 a、平行间隔 g 怎样改变带宽，适用范围和误差是多少；并经过没有参与拟合的新仿真检验 |
| G2 | 把均匀模型上已经做成的事搬到弯折模型：给定目标（带宽、S11）和弯折形状，输出几何尺寸 | 对冻结的目标清单，输出的几何经 HFSS 复核，逐个如实报告达标与否 |
| G3 | 更宽空间的逆设计（带宽 5–8 GHz）和论文之外的可量化规律 | 见第 7 节 |

硬性约束：

| 项目 | 约定 |

## 2. 结构、变量和带宽的定义

### 2.1 几何

单位 mm，频率 GHz。槽线主段 Ls1 两端各接一段连接段 Ls2，再接一段折回来与主段平行的折臂 Ls3。

| 符号 | 含义 | 现有 80 次仿真的范围 |
|---|---|---|
| Wm、Lm | 微带枝节的宽和长 | 1.700–1.946，6.515–6.651 |
| Ws | 槽宽 | 0.327–0.439 |
| Ls1 | 槽线主段长 | 11.94–12.80 |
| a = Ls3 − Ws | 折臂长 | 只有 1.4 和 1.8 两档 |
| g = Ls2 − 2Ws | 主段与折臂之间的净间隔 | 固定 0.55 |
| Lpath = Ls1 + 2Ls2 + 2Ls3 | 槽线总路径长 | 18.46–19.38 |
| ρ = 2(Ls2 + Ls3) / Lpath | 折叠部分占总路径的比例 | 0.317–0.379 |
| η = Ls2 / (Ls2 + Ls3) | 连接段在单侧折叠路径里的比例 | 0.361–0.437 |

ρ、η 是用户周报（2026-08-02）里提出的无量纲变量。**实验的控制变量用 a 和 g，ρ 和 η 作为导出量一并记录。** 理由：每次为了把中央谷调回 6.72 GHz 而改 Ls1 时，ρ 会跟着变，a 和 g 不会。现有数据里 a 与 ρ 完全同步变化，分不清带宽跟的是哪一个，第 6 节的实验要把它们分开。

阶段 0 要先从 `hfss/INV01_A14.aedt` 核对两件事并写进记录：Ls2、Ls3 是按槽的外沿还是中心线标注的；折臂朝哪一侧折、折臂端头离微带线边缘多远。

### 2.2 理论坐标

名义阻抗由直线模型算出（`analysis/line_models.py`）：P = Zm·Zs / 2500，R = Zm / Zs。它们不是从弯折 HFSS 里提取的等效值。

等效电路是论文 Fig. 2(b)：串联开路微带枝节、两个并联短路槽线枝节、再接一个串联开路微带枝节。对每条 HFSS 曲线拟合 4 个参数：等效归一化阻抗 z′m、z′s，微带枝节和槽线枝节各自的四分之一波长频率 fm、fs。

```
z′m = N1²·Zm/50      z′s = N2²·Zs/50
P_eff = z′m·z′s      R_eff = z′m / z′s
```

N1、N2 是论文的变比。弯折对电路的影响，全部通过 N2（也就是 z′s）和 fs 进入。

### 2.3 带宽的五种口径

“弯折使带宽变窄多少”的答案取决于口径，五种都要算，不能混用。

| 记号 | 定义 | 什么时候用 |
|---|---|---|
| BW20 | 包含 6.72 GHz 的、S11 连续 ≤ −20 dB 的区间宽度 | 只在两个内峰都 ≤ −20 dB 时有意义。内峰一越过 −20 dB，它就从约 6 GHz 跳到约 2 GHz，不能用来看平滑趋势 |
| BW15 | 同上，门限 −15 dB | 现有数据里处处有定义、随几何平滑变化；固定线宽的弯折阶梯用它做主指标 |
| BW_S21 | S21 ≥ −2 dB 的主带宽 | 仓库已有的带宽公式预测的就是它 |
| BW_joint | S11 ≤ −20 dB 且 S21 ≥ −2 dB 的中心连续段（`analysis/lib.py`） | 最终是否达标 |
| BW_circ(L) | 由提取的 P_eff、z′m、f0 按附录 A.3 的闭式解算出的带宽，L 为门限 | 检验“电路能否解释带宽变化” |

另有**等纹波带宽**：把内峰调到同一电平（−21 dB）之后的 BW20。它回答“纹波一样时，弯折还要付出多少带宽”，是 G1 最终要报告的量。

## 3. 已经用过的方法

### 3.1 均匀模型（用户此前的工作，数据不在本仓库）

来源是用户 2026-07-11、07-20、07-25、08-02 的四份周报。做法是“TXLINE 理论初值 + 机器学习偏差修正”：

```
最终几何 = TXLINE 理论几何 + 机器学习预测的偏差
```

- 输入：目标等效阻抗 Zm′、Zs′，P_eff、R_eff，TXLINE 给出的理论 Wm、Lm、Ws、Ls，以及是否到达 TXLINE 边界的标记。
- 输出：Wm、Lm、Ws、Ls 四个尺寸相对 TXLINE 理论值的偏差。
- 数据从 400 条增加到 650 条、1000 条；模型用随机森林、XGBoost，1000 条时加了共享 MLP。

几何预测误差（独立测试集 MAE，mm）：

| 参数 | 400 条 | 650 条 | 1000 条，随机森林 | 1000 条，共享 MLP |
|---|---:|---:|---:|---:|
| Wm | 0.0269 | 0.0219 | 0.01279 | 0.01310 |
| Lm | 0.0120 | 0.0084 | 0.00709 | 0.00728 |
| Ws | 0.0100 | 0.0089 | 0.00569 | 0.00504 |
| Ls | 0.0376 | 0.0235 | 0.01933 | 0.01933 |

400 条和 650 条两列的测试集不同，不能直接逐格比较。650 条时相对直接用 TXLINE 几何，四个参数的 MAE 降低 95–98%。

周报里对后续最有用的四点：

1. **验证方式越严，误差越大。** 650 条时，随机 8:2 划分的 MAE 是 Wm 0.0219、Ls 0.0235；嵌套交叉验证是 0.0305、0.0348；整批来源留出是 0.0474、0.0499，约为随机划分的两倍。本计划一律按设计家族分组验证，并用前瞻点做最终检验。
2. **几何预测准不等于性能达标。** 把预测几何重新仿真：400 条模型的 6 组验证，带宽平均差 0.047 GHz，最差 S11 平均差 0.25 dB，6 组里 3 组内峰差超过 0.5 dB；650 条模型的 4 组验证，带宽平均差 0.095 GHz，最差 S11 差 0.18 dB，内峰差的差 0.22 dB。周报的结论是模型适合当 HFSS 初始几何生成器，不能凭几何预测保证性能达标。
3. **最敏感的是两个内峰的平衡。**
4. **三类数据问题**：输入几乎相同而修正量不同的冲突样本；同一设计系列的样本同时出现在训练集和测试集；边界、低阻抗区样本稀疏。

周报对弯折模型的设想和已有观察：

- 07-11 的下一步里已经写明：在弯折模型上验证均匀模型的思路是否同样有效，并找出弯折和带宽的关系。本计划就是做这件事。

### 3.4 均匀模型的做法能不能搬到弯折模型

能，而且两边学的是同一组东西。均匀模型学的 4 个偏差，在等效电路里各有对应：

| 均匀模型学的偏差 | 弯折模型里对应的量 | 含义 |
|---|---|---|
| Wm 的偏差 | N1 | 微带的等效阻抗与名义值之比 |
| Ws 的偏差 | N2 | 槽线的等效阻抗与名义值之比 |
| Lm 的偏差 | ΔLm | 微带枝节的等效长度修正 |
| Ls 的偏差 | ΔLs | 槽线的等效长度修正 |

搬过来时有三处不同：

1. **多了弯折形状。** 把 a、g 当作输入（由设计者指定），输出仍然是 4 个量：Wm、Ws、Lm、Ls1。同一目标对应多组几何的问题，就靠指定弯折形状来消除。
2. **Ls 的偏差不能直接沿用。** 均匀模型里实际的 Ls 比理论值短 1.0–2.75 mm（按周报图 1 的读数）；弯折模型里总路径 Lpath 比半波长长约 1.6 mm（4.3 节）。符号相反，因为折叠部分的电长度打了折扣。
3. **标签的取法不同。** 均匀模型的标签是“调到达标之后的几何”，每个样本都要先调好，而且调到哪里并不唯一，周报里的冲突样本就是这样来的。本计划的标签是从每条 HFSS 曲线提取的电路参数，任何一次仿真都能用，不需要先调到达标，标签也唯一。

数据量上，弯折模型现在只有 80 条，本计划的弯折部分再加约 150 条，不足以单独训练一个可信的随机森林或 MLP。所以主路线用规律公式，机器学习只学公式剩下的残差，并且在同样的划分上与公式对比（阶段 5）。

### 4.3 弯折对带宽的影响：现在能量化到什么程度

同一家族、同样的 Wm 和 Ws，a 从 1.4 增到 1.8 mm（Δa = 0.4 mm，Δρ = +0.039），Lm、Ls1 相应重调。共 47 对，其中 24 对来自初始批。下表是 47 对的均值 ± 标准差。

| 量 | 变化 | 方向一致的对数 |
|---|---:|---:|
| N2 | −0.0086 ± 0.0010 | 47/47 减小 |
| z′s | −2.02% ± 0.23% | 47/47 减小 |
| P_eff | −0.028 ± 0.004 | 47/47 减小 |
| R_eff | +0.0147 ± 0.0021 | 47/47 增大 |
| 内峰平均电平 | −0.44 ± 0.13 dB | 47/47 降低 |
| BW15（HFSS） | −57 ± 11 MHz | 47/47 变窄 |
| BW15 的低边 / 高边 | +47 MHz / −10 MHz | 低边 47/47 上移 |
| BW_circ(−15 dB) | −71 ± 18 MHz | 47/47 变窄 |
| 只让 z′s 变化时的 BW_circ(−15 dB) | −79 ± 9 MHz | 47/47 变窄 |
| BW_S21 | −2 ± 11 MHz | 18 对变宽、29 对变窄 |
| S21 −2 dB 高边 | +28 ± 15 MHz | 45/47 上移 |
| 剩余功率 1 − \|S11\|² − \|S21\|²，9.5 GHz 处 | −0.016 ± 0.002（约 0.196 降到 0.180） | 47/47 减小 |
| 带内最小 S21 | +0.086 ± 0.017 dB | 47/47 改善 |
| 槽线长度修正（半波长 − Lpath） | −0.216 ± 0.013 mm | 47/47 |

折算成每毫米折臂（只是这两档之间的局部斜率）：z′s 降 5.1%，BW15 窄 143 MHz，BW_S21 基本不变。

由此得到五点：

1. **弯折主要通过降低槽线的等效阻抗来影响带宽。** 折臂变长，N2 变小，z′s 变小；P_eff 随之变小，纹波降低；R_eff 随之变大，带宽变窄。只让 z′s 变化，电路算出的带宽变化是 −79 MHz，HFSS 实测是 −57 MHz，方向和量级一致。
2. **电路没有解释的部分约 14–22 MHz**，而且实测带宽的变窄几乎全在低边。这部分差别来自哪里，现在不知道。
3. **答案取决于带宽口径。** 反射口径的 BW15 明显变窄，传输口径的 BW_S21 基本不变，因为高频端损耗减小，把 S21 的高边推高了 28 MHz。BW20 则会因为内峰跨过 −20 dB 而整段跳变，不能直接比较。
4. **高频端的剩余功率确实减小了**，与论文“折叠减小辐射损耗”的说法方向一致。但剩余功率里还有导体损耗和介质损耗，现在不能说减小的都是辐射。
5. **用户周报里的“总电长度约束”得到支持。** 在 fs 处，沿 Lpath 的电长度是 196.6° ± 1.9°，不是 180°；弯折和互耦带来约 −17° 的修正。这个修正可以由几何预测：`半波长 − Lpath = 1.171 − 5.064·Ws − 0.538·a`（mm），残差标准差 0.029 mm。折臂每加长 1 mm，路径长了 2 mm，电长度只多了约 1.46 mm。

论文的数据可以做一个量级核对（论文基板 εr = 3.38、f0 = 6.85 GHz，与本仓库不同，只能看量级）：

| 论文设计 | 均匀 N2 → 折叠 N2 | z′s 变化 | 折叠尺寸换算 | 折臂每毫米的 z′s 降幅 |
|---|---|---:|---|---:|
| zm = 1.0，zs = 2.1 | 0.861 → 0.825 | −8.2% | a = 1.93，g = 0.71，ρ = 0.416 | 4.2% |
| zm = 0.8，zs = 2.625 | 0.853 → 0.821 | −7.4% | a = 1.85，g = 0.53，ρ = 0.422 | 4.0% |

论文从直槽到折叠的平均降幅是每毫米折臂 4.0–4.2%，本仓库 1.4 到 1.8 mm 之间的局部斜率是 5.1%，量级一致。论文尺寸到 a、g 的换算假设它的 Ls2、Ls3 与本仓库的标注方式相同，这一点没有核实。

### 4.4 与周报里 4 个弯折点的对照

07-25 周报的 4 个点里，折臂加长 0.6 mm，R_eff 升高 0.085，方向与 4.3 节一致。但有一处对不上：周报里 −2 dB 带宽随之减小了 244 MHz，而本仓库的 47 对里 BW_S21 基本不变。可能的原因是那 4 个点的线宽没有保持一致（周报自己也说“其他理论量没有完全保持一致”），也可能是两处的 R_eff 提取方法不同。阶段 2 的阶梯实验线宽严格不变，可以把这一点查清楚。

### 4.5 现在还不知道的

- a 只有两档，画不出曲线：z′s 随 a 是线性的还是会饱和，不知道。
- g 从来没有变过，它的作用完全未知。
- a 与 ρ 同步变化，带宽跟的是折臂的绝对长度还是折叠比例，分不清。
- 没有同一基板、同一设置下的直槽对照（a = 0）。
- 纹波调到一样之后，弯折是否还有带宽代价，没有数据。
- 剩余功率里辐射占多少，没有分解。
- 以上结论都在窄区内（带宽约 5.9 GHz 附近），更宽或更窄的设计里是否成立，不知道。

## 5. 待检验的假设

每条假设在仿真之前先把预测值冻结存档，仿真之后再对比。

| 编号 | 假设 | 定量形式 | 怎样算被推翻 |
|---|---|---|---|
| H1 | 弯折使槽线等效阻抗下降，降幅由 a、g 决定 | z′s(a, g) / z′s(直槽) = 1 − κ(a, g)。候选形式：κ = k·a；κ = k·ρ；κ = k·a·exp(−g/g0)。窄区内 g = 0.55 时 k ≈ 0.05 /mm | 三种形式的留一阶梯交叉验证误差都大于 z′s 的 1% |
| H2 | 固定线宽时，带宽的变化可以由 z′s 的变化经闭式解算出 | ΔBW15 ≈ BW_circ(P_eff·(1 − κ), z′m) − BW_circ(P_eff, z′m) | 预测与 HFSS 之差超过 30 MHz，或随 a 系统性增大 |
| H3 | 固定线宽时，弯折对 BW_S21 的影响远小于对反射带宽的影响 | \|ΔBW_S21\| < 0.2·\|ΔBW15\| | 在整个 a、g 范围内不成立。周报的 4 个点与此不符（4.4 节），要查清原因 |
| H4 | 弯折减小高频端的辐射损耗 | 无耗对照（PEC、tanδ = 0）的剩余功率随 a 单调减小 | 无耗对照的剩余功率不随 a 变化 |
| H5 | 槽线的电长度可以由“总路径长 + 弯折修正”预测 | 半波长 − Lpath = c0 + c1·Ws + c2·a + c3·g，或折臂按有效系数计入 | 预测 fs 的误差超过 15 MHz |
| H6 | **纹波调到一样之后，弯折几乎没有带宽代价** | 把 Ws 加宽，使 z′s 回到直槽的值，P_eff 和 R_eff 同时复原。窄区内估算每毫米折臂需加宽约 0.07 mm。预测等纹波 BW20 的变化小于每毫米折臂 20 MHz | 等纹波 BW20 随 a 的变化明显大于此值。这时说明弯折还改变了枝节电抗的频率斜率，电路里要补一个元件，这本身是新发现 |
| H7 | 间隔 g 越大，互耦越弱，κ 越小 | κ 随 g 单调减小，g 很大时趋于只剩拐角效应的常数 | κ 不随 g 单调变化 |
| H8 | 弯折使同样带宽所需的槽更宽，所以压低了能做到的最大带宽 | 给定 a、g，可行的最大 B 由 Ws 上限和 S21 ≥ −2 dB 决定 | 留到第 7 节的宽空间数据检验 |

H6 是整个问题的核心。如果它成立，“弯折使带宽变窄”只是固定线宽时的表观现象，设计上把槽加宽一点就能补回来，弯折净赚了损耗的改善。如果它不成立，剩下的那部分就是弯折的本征带宽代价，要给出它随 a、g 的公式。

### 阶段 1：基线与噪声（约 12 次，约 4 机时）

目的：确认新一批仿真与归档数据可比，并测出指标的数值噪声。

- 网格设置沿用归档数据：目标 10–11 万单元，MaxDeltaS = 0.005，插值扫频 0.01–15 GHz。这满足 ΔS < 0.05 的要求，也使 80 次旧数据可以直接当作阶梯上的点。弯折效应是小量（每 0.4 mm 折臂约 57 MHz），这一部分不用粗网格。
- 重跑 3 个基准几何各 1 次（阶段 2 选定的 3 个家族的 a = 1.8 版本），与归档结果对比。
- 中间那个基准几何做 Ws 的扰动阶梯：0、±0.002、±0.005、±0.01、±0.02 mm，共 9 点。

判据：重跑与归档的差别，内峰 ≤ 0.1 dB、中央谷 ≤ 10 MHz、BW15 ≤ 10 MHz；由扰动阶梯得到各指标的噪声 σ（数据点相对二次拟合曲线的残差标准差）。如果重跑与归档不一致，停下来报告，不进入阶段 2。

### 阶段 2：固定线宽的弯折阶梯（约 37 个设计，约 75 次，约 25 机时）

每个设计点线宽固定不变，只改弯折；Ls1、Lm 重调，使中央谷回到 6.72 ± 0.03 GHz、内峰差 ≤ 0.5 dB。

基准线宽取 3 个已有家族：R 最小的、居中的、最大的各一个（从 `model/DATASET.json` 里按 R 排序选出，写进 `design_list.csv`）。这样 a = 1.4、1.8，g = 0.55 的点已经有数据。

| 子实验 | 变化的量 | 取值 | 新设计数 |
|---|---|---|---:|
| E0 直槽对照 | 无折叠，直槽长度按半波长重调 | 每个基准 1 个 | 3 |
| E1 折臂阶梯 | a，g 固定 0.55 | 0.6、1.0、（1.4）、（1.8）、2.2、2.6、3.0 | 15 |
| E2 间隔阶梯 | g，a 固定 1.8 | 0.25、0.40、（0.55）、0.80、1.20、2.00 | 15 |
| E3 交叉点 | (a, g)，只做居中的基准 | (1.0, 0.25)、(1.0, 1.20)、(2.6, 0.25)、(2.6, 1.20) | 4 |

括号里的取值已有归档数据。a、g 的上下限要经用户确认（第 9 节），并通过 0.5 步的可行性检查。

重调规程，每个设计点最多 3 次仿真：

1. 用规律链算出 Ls1、Lm 的初值，仿真。
2. 拟合电路，得到 fm、fs。按附录 A.4 的目标值 fm* = 6.622、fs* = 6.588 GHz 算出长度的修正量（Ls1 的修正 = L_half·(fs/fs* − 1)，L_half 是 fs 处的槽线半波长；Lm 用四分之一波长同理），再仿真。
3. 仍不满足中央谷和内峰差的要求，再修正一次。三次之后仍不满足，记为“未调准”，保留全部数据，不再追加。

每次仿真都保存，都是有效数据；重调过程中的点标注为“调参所得”。

E0 的直槽模型需要另建一个没有折臂的工程变体，放在 `uniform_control/`。

判据：每个阶梯至少 5 个调准的点；每个调准点都有电路提取结果和五种带宽。

### 阶段 3：等纹波对比与损耗分解（约 40 次，约 14 机时）

目的：检验 H6 和 H4。

- 取居中和 R 最小的两个基准。a 取 0（直槽）、0.6、1.4、2.2、3.0，g = 0.55。
- 每个点调 Ws（Wm 不动），使两个内峰的平均电平为 −21.0 ± 0.15 dB；同时重调 Ls1、Lm 保持中央谷和内峰平衡。Ws 的初值由规律链给出，每个点最多 3 次仿真。
- 每个调准的点记录：BW20、BW15、BW_S21、BW_joint、所需的 Ws、提取的 P_eff 和 R_eff。
- 损耗分解：每个调准的点加跑一个无耗对照（铜改为理想导体，tanδ = 0，几何不变）。无耗对照的剩余功率就是辐射功率加数值误差。也可以改用辐射边界上的功率积分，但要说明用的是哪种方法。

判据：两个基准各有至少 4 个调准的等纹波点，并有对应的无耗对照。

### 阶段 4：拟合规律并做前瞻检验（约 8 次，约 3 机时）

1. 用阶段 2、3 的数据拟合：
   - κ(a, g)：比较 H1 的三种候选形式，按“留出一整条阶梯”交叉验证选型。
   - 槽线长度修正：在附录 A.2 的形式里加入 g 项。
   - 固定线宽的带宽变化：由 κ 经闭式解预测，报告与 HFSS 的残差；残差若有规律，拟合成 a、g 的函数。
   - 等纹波带宽代价：BW20 对 a 的斜率及其不确定度。
   - 辐射功率对 a 的关系。
2. 冻结全部系数，记录文件哈希。
3. 前瞻检验：另取 8 个没有出现过的组合，例如 a = 2.0、g = 0.70，a = 0.8、g = 0.40，分布在 3 个基准上。预测先冻结，仿真只做一次，结果不再用来调系数。

判据（建议值，供用户调整）：前瞻点上 z′s 的预测误差 ≤ 1%，fs ≤ 15 MHz，BW15 ≤ 30 MHz，内峰 ≤ 0.2 dB。没有达到就如实报告，这 8 个点改标为“调参所得”，补点后另取一组新点重做。

### 阶段 5：把弯折作为输入的逆设计（约 12 次，约 4 机时）

这一步对应均匀模型上已经做成的事。输入是目标带宽 B、纹波目标和弯折形状 (a, g)；输出是 4 个量：Wm、Ws、Lm、Ls1。弯折形状由设计者指定，同一个目标对应多组几何的问题就消失了，输出和均匀模型一样是 4 个量。

- 主路线：规律链直接求解（附录 A.4 加上阶段 4 的 κ(a, g) 和长度修正），不用神经网络。
- 对照路线：用全部数据训练随机森林和小型 MLP，输入 [目标 z′m、z′s、P_eff、R_eff、a、g、规律链给出的初始几何]，输出相对初始几何的 4 个偏差，做法和均匀模型一致，便于两边比较。按设计家族分组交叉验证，同时报告随机划分的结果，看两者差多少。样本只有约 230 个，预计网络不会比规律链好，如实报告。
- 验证：目标清单先冻结。B 取窄区内的 2 个值（例如 5.6、6.0 GHz），每个 B 配 3 种弯折形状，共 6 个设计；每个设计在 HFSS 上复核，未达标的允许按阶段 2 的重调规程修正一次。

判据：逐个报告是否达标（S11、S21、中央谷、内峰差），以及预测与实测的差。同时按均匀模型周报的口径报告带宽、最差 S11、内峰差、最小 S21 的平均绝对偏差，与均匀模型的闭环结果（带宽 0.047–0.095 GHz、最差 S11 0.18–0.25 dB、内峰差约 0.22 dB）并列比较。

带宽 5–8 GHz 需要的尺寸范围，由窄区规律外推得到，只用来确定采样中心（a = 1.6、g = 0.55，纹波目标 −21 dB）：

| 5.0 | 1.035 | 62.7 | 91.2 | 1.20 | 0.165 | 6.71 | 11.91 |
| 5.6 | 0.769 | 53.2 | 100.9 | 1.61 | 0.270 | 6.63 | 12.19 |

步骤：

1. **网格实验**（约 200 次）。2 个基准几何，约 2.5 万、4 万、6 万、8 万、10 万五档网格，各做尺寸扰动阶梯，外加约 18–20 万的参考档。目的是找到既快又稳的网格档。归档记录表明 ΔS < 0.05 在约 1 万网格时就已满足，所以 ΔS 只能当下限，档位要靠实测的噪声来定。探索档的判据：内峰噪声 σ ≤ 0.05 dB、中央谷 σ ≤ 5 MHz、带边 σ ≤ 10 MHz。验证档的判据：与参考档相比，内峰偏差 ≤ 0.1 dB、中央谷 ≤ 10 MHz、带边 ≤ 20 MHz。
2. **采样**（约 132 次）。采样范围：Wm 1.0–4.5，Ws 0.12–1.3，a 和 g 的范围取阶段 2 证实可行的范围。先做 12 个种子点（B = 5.0、5.6、6.2、6.8、7.4、8.0 GHz，各配两个 a），预测先冻结；用结果重新标定规律链；再撒约 120 个 Sobol 点，其中约 96 个在“带宽、P_eff、a、g、fm 和 fs 的偏移”这组坐标里撒，约 24 个直接在几何范围里撒。
3. **模型**。M0 是规律链；M1 是主模型：网络输出相对规律链的修正量（ΔN1、ΔN2、Δfm、Δfs），再经等效电路算出曲线，独立训练 5–10 个取平均，离散度作为不确定度 σ；M2 是不带电路的纯数据网络，做对照。
4. **主动学习**（60–80 次）。每批 10–20 个点，一半取 σ 最大的，一半取预测落在 −20 dB 悬崖附近的。
5. **验证**。按家族分组交叉验证；留出 B > 7.4 GHz 的点检验外推；模型冻结后另撒约 20 个点做一次性前瞻检验。目标误差：内峰 ≤ 0.2 dB，内峰差 ≤ 0.15 dB，中央谷 ≤ 10 MHz，BW20 ≤ 100 MHz，最小 S21 ≤ 0.1 dB。
6. **逆设计**（约 30 次复核）。目标 B = 5.0、5.6、6.2、6.8、7.4、8.0 GHz，每个目标输出 3–5 组明显不同的几何。在 M1 上从约 100 个起点优化，约束取“预测值 + 2σ ≤ −20.4 dB”等；聚类；取整到 0.001 mm；每个尺寸 ±0.01 mm 扰动下仍达标；在验证档网格上复核并加离散频点。未达标的最多重做 3 轮。B = 8 GHz 可能做不到，做不到就报告能达到的最大带宽和限制它的指标。
7. **规律**。在宽空间里重新检验：纹波只由 P_eff 决定；变比和长度修正随几何的变化；带宽闭式解；−20 dB 悬崖的位置是否随 B 移动；频带中心偏移（现有 10 个达标点的 −20 dB 频带中心比 6.72 GHz 低 0.11–0.16 GHz）；每个 B 能达到的最低纹波；损耗随槽宽的变化；以及 H8。

## 附录 A：公式和系数

以下系数由归档的 80 次仿真拟合，只在 4.2 节末尾所说的窄区内成立。单位：长度 mm，阻抗 Ω，频率 GHz。

### A.1 等效电路

```
θm = (π/2)·f/fm          θs = (π/2)·f/fs
Z1 = −j·z′m·cot θm       Y = −2j·cot θs / z′s
A = D = 1 + Z1·Y         B = Z1·(2 + Z1·Y)        C = Y
S11 = (B − C) / (2A + B + C)        S21 = 2 / (2A + B + C)
```

拟合对象是 2–11.5 GHz 内 S11 的线性幅度，4 个自由参数，初值取名义 zm、zs 和 6.72 GHz。实现见 `experiments/fold_bandwidth_20261110/offline_fold_analysis.py`。

### A.2 变比和长度

```
N2 = 0.2655 − 0.0216·a + 0.1506·ln Zs − 0.0239·ln Zm        (R² = 0.985)
N1 = 1.0343 + 0.0029·a + 0.0206·ln Zs − 0.0328·ln Zm        (R² = 0.830)

fm = c / (4·(Lm + ΔLm)·sqrt(εeff,m(fm)))
fs = c / (2·(Ls1 + 2Ls2 + 2Ls3 + ΔLs)·sqrt(εeff,s(fs)))
ΔLm = 0.1561 − 0.1249·Wm + 0.3751·Ws + 0.0607·a             (R² = 0.990)
ΔLs = 1.9644 − 0.4017·Wm − 5.2118·Ws − 0.5389·a             (R² = 0.998)
```

c = 299.792458 mm·GHz；εeff 由线模型在 fm（或 fs）处计算，所以要迭代。4.3 节第 5 点的三参数式是 ΔLs 的简化形式。

### A.3 纹波和带宽的闭式解

fm = fs = f0 时，令 u = z′m·cot θ，p = P_eff：

```
|S11|² = F² / (1 + F²)        F = u·(u² − p + 1) / p
内峰处  F_max = (2/p)·((p − 1)/3)^1.5                        （论文式 (7)）
p = 1.546 时内峰为 −20 dB；p = 1.494 时为 −21 dB

门限 L（dB）：F_L = sqrt(r / (1 − r))，r = 10^(L/10)
带边：u_e 是 u³ − (p − 1)·u − p·F_L = 0 的最大实根
θ_e = arctan(z′m / u_e)        BW = 2·f0·(1 − 2θ_e/π)
```

### A.4 逆设计初值

```
给定 B 和纹波目标：由 A.3 解出 p 和 u_e
θ_e = (π/2)·(1 − B/(2·f0))      z′m = u_e·tan θ_e      z′s = p / z′m
Zm = 50·z′m / N1²               Zs = 50·z′s / N2²       （N1、N2 依赖 Zm、Zs，迭代几次收敛）
由线模型反解 Wm、Ws；由 A.2 定出 Lm、Ls1，使 fm = 6.622、fs = 6.588
```

fm、fs 的目标值来自窄区内的两条局部拟合：中央谷 `fc = 2.8511 + 2.0622·fm − 1.4858·fs`，内峰差 `34.89·(fm − fs) − 1.212`。令 fc = 6.72、内峰差为 0 即得。这两条只在窄区内可用。

### A.5 线模型

微带：Hammerstad–Jensen 有限厚度公式加 Kirschning–Jansen 色散。槽线：Janaswamy–Schaubert 闭式公式，适用 2.22 ≤ εr ≤ 3.8、0.0015 ≤ w/λ0 ≤ 0.075，6.72 GHz 时对应槽宽约 0.07–3.3 mm。实现和出处见 `analysis/line_models.py`。
