# Fig.8 弯折模型：24配置规律分析

分析日期：2026-10-26。数据仅为已收尾的24项弯折模型及相关局部探针；没有混入均匀模型数据，没有新启动HFSS求解或hook。

**已找到可用于当前范围初步设计的几何—带宽经验关系：微带宽度Wm和槽宽Ws主导−2 dB带宽，折臂变化对最终调谐设计的带宽影响较小；折臂加长后，带内反射与传输在本批配对结果中一致改善。尚未证明跨间隔、跨材料的物理P/R带宽定律。**

![24配置规律图](fig8_laws.png)

## 1. 数据能回答什么

24项是4种Wm（0.90/1.20/1.60/2.00 mm）×3种Ws（0.30/0.44/0.58 mm）×2种净折臂a（1.40/1.80 mm）。所有净间隔g均为0.55 mm，不能从这批数据识别g的效应。

定义：a=Ls3−Ws；g=Ls2−2Ws；几何路径Lpath=Ls1+2Ls2+2Ls3−4Ws。改变Ws时同时改变Ls2、Ls3，以保持a和g。所有选中设计均通过原中心位置与等峰判据，Lm和Ls1已分别调谐，因此本文比较的是“调谐后的设计族”，不是固定其余每个尺寸的单变量因果实验。

实际材料εr=3.55、tanδ=0.0027、h=0.813 mm。中央反射谷目标6.72±0.03 GHz，不能与−2 dB带边中点或旧P/R提取参考6.85 GHz混用。

**24项通过不等于24项全部使用10万网格。** 最终有效数据保留8项超过11.2万的历史结果，总范围100,013–243,615单元；6项有参考恢复/诊断文件记录。为检验结论是否由这些差异造成，另外分析16项100,000–112,000单元且无该记录的数据。该子集仍不代表完全一致的数值策略（例如D11G05插值容差为0.5%，部分其他项为1%）。4项历史接受、20项范围接受的层级原样保留。

24条1500点曲线逐条重新提取−2 dB带边，与冻结指标的BW最大差为0.0e+00 GHz；源交付文件哈希校验通过。有限直接点核验不等于全网格误差为零。

## 2. 宽度规律：两个宽度增大，带宽都增大

下表为同宽度下两个折臂的平均−2 dB带宽，单位GHz：

| Wm / mm | Ws=0.30 mm | Ws=0.44 mm | Ws=0.58 mm |
|---|---:|---:|---:|
| 0.90 | 6.244 | 6.566 | 6.791 |
| 1.20 | 6.492 | 6.824 | 7.036 |
| 1.60 | 6.701 | 7.063 | 7.290 |
| 2.00 | 6.852 | 7.199 | 7.452 |

- 固定Ws和折臂等级，Wm从0.90增至2.00 mm，带宽增加0.588–0.682 GHz，平均0.634 GHz；18个相邻宽度比较全部为正。
- 固定Wm和折臂等级，Ws从0.30增至0.58 mm，带宽增加0.515–0.622 GHz，平均0.570 GHz；16个相邻宽度比较全部为正。
- 对反射水平，两种宽度方向相反：Wm增加使S11双内峰平均水平下降，Ws增加使其上升。具体示例：Ws=0.30时，Wm=0.90→2.00的双峰平均水平（两折臂再平均）约−14.33→−23.38 dB；Wm=1.20时，Ws=0.30→0.58约−16.69→−12.82 dB。因此可以同时考虑带宽与反射指标来选两种宽度。

这是一条当前范围内稳定的响应趋势。尚未进行几何点之间的制造容差或新材料验证。
另一个有设计价值的结果是：**近似相同带宽，可以对应明显不同的反射水平。** 固定长折臂a=1.8 mm、g=0.55 mm的三个实际点为：

| 配置 | Wm / mm | Ws / mm | −2 dB带宽 / GHz | S11双内峰平均水平 / dB |
|---|---:|---:|---:|---:|
| D03G05 | 0.90 | 0.58 | 6.815 | −11.19 |
| D05G05 | 1.20 | 0.44 | 6.842 | −14.34 |
| D10G05 | 2.00 | 0.30 | 6.858 | −23.66 |

三个带宽相差不到44 MHz，但反射双峰水平相差约12.5 dB。由经验公式推导，在近似恒定带宽下Ws与Wm约满足Ws∝Wm^(−0.9215)；沿“微带更宽、槽更窄”的方向可作为改善回波的选型方向。该等带宽关系是模型推导，不是新仿真结论，仍受本次宽度范围和调谐条件限制。

## 3. 可复用的局部带宽公式

选用易解释、在不同子集上表现稳定的三系数模型：

```text
BW_−2dB / GHz ≈ 6.80457
                 + 0.79817 ln(Wm / 1.20 mm)
                 + 0.86618 ln(Ws / 0.44 mm)
```

ln为自然对数。只在本报告宽度范围、g=0.55、a=1.4或1.8、材料和中心/等峰调谐条件下使用。它省略了较小的折臂修正，不是未调谐任意尺寸的预测公式。拟合R²=0.99433，训练RMSE=25.3 MHz。

每次留出同一宽度组合的两个折臂点，其余22点拟合，再预测这两个点，避免把同宽度的配对点同时放入训练与测试。另做整宽度水平留出检验：

| 检验方式 | MAE / MHz | RMSE / MHz | 最大绝对误差 / MHz |
|---|---:|---:|---:|
| 全部24项：留整组宽度 | 22.9 | 29.7 | 60.1 |
| 全部24项：留整个Wm水平 | 31.7 | 38.9 | 79.1 |
| 全部24项：留整个Ws水平 | 26.4 | 32.1 | 68.0 |
| 16项约10万网格子集：留整组宽度 | 21.7 | 28.1 | 57.6 |

16项子集独立拟合的系数为6.80608、0.78358、0.88379，与24项结果接近。新增折臂线性项后，整组留出RMSE仅从29.67变为29.06 MHz；在16项子集反而由28.07变为28.25 MHz，支持先不把小折臂项写成强定律。

二次多项式在24项上留组RMSE更小（21.50 MHz），但16项子集留组RMSE变为33.24 MHz，且只剩两种Ws训练水平时无法识别Ws二次项。因此不将复杂拟合优先作为主公式。

更粗略的二系数压缩式为 BW/GHz≈6.79935+0.82858 ln[(Wm·Ws)/(0.528 mm²)]，留组RMSE30.94 MHz。这里是**几何宽度乘积，不是阻抗乘积P**。

所有以上误差都是现有数据事后交叉验证结果。比较过多个候选模型，数值不能充当完全独立验证或未来最坏误差保证；最终六个新点的前瞻检验尚未运行。

## 4. 折臂规律：带宽小变化，带内表现更一致

12对同宽度配置将a从1.40增加到1.80 mm，同时重新调谐Lm/Ls1：

| 指标 | 本批配对变化 |
|---|---|
| −2 dB带宽 | 平均+18.48 MHz；范围−39.28至+76.39 MHz；10对增加、2对减小 |
| 约10万网格且无参考恢复记录的6对 | 均增加，范围+5.78至+76.39 MHz，平均+22.07 MHz |
| S11双内峰平均水平 | 12对全部降低，平均降低0.330 dB，范围0.066–0.573 dB |
| 固定4–9 GHz内最差S21 | 12对全部改善，平均+0.074 dB，范围+0.053至+0.117 dB |
| 同时满足S11≤−10 dB与S21≥−2 dB的带宽 | 平均−8.81 MHz，6对增加、6对减小 |

带宽结论依赖指标定义，不能用−2 dB带宽的轻微增加推出有效匹配带宽也增加。两对−2 dB变窄的结果均含历史数值策略差异；即使同子集都小幅增加，也不能把调谐和残余数值影响全归给折臂。

导师提出的“弯折降低辐射边缘损耗，并可能稍减本征带宽”与这里并不矛盾：本批比较的是两种已弯折且分别调谐的结构，测量的是含匹配和损耗的实际S参数阈值带宽，没有直槽对照。现有24项不能区分辐射、导体、介质或失配对改善的贡献。

旧五点单频场积分给出过局部减辐射线索，但它采用较早端口协议，不混入当前24项回归。当前24项也不能单独确认全带减辐射机理。

## 5. 长度调谐规律：不能只保持几何总路径

折臂增加0.40 mm时，保持几何总路径的简单规则会要求Ls1减少0.80 mm。实际通过设计的Ls1平均减少0.646 mm，中位数0.648 mm；约10万网格6对平均减少0.663 mm。Lm平均减少0.033 mm。全部12对最终几何路径反而增加0.026–0.400 mm。

因此，从短折臂迁移到长折臂，可把“Ls1减约0.65 mm、Lm减约0.03 mm”用作此窗口内的起始估计，再按本配置响应校正；只有两个折臂水平，不能当成任意折臂长度的通用比例式。

修正期间的三个同配置局部探针给出可直接用于调谐的方向。峰差定义为低频S11内峰减高频S11内峰：

| 配置 | 增加 Ls1 0.10 mm：峰差 / 中央谷变化 | 增加 Lm 0.05 mm：峰差 / 中央谷变化 |
|---|---:|---:|
| D01G02 | +0.778 dB / +40 MHz | -1.057 dB / -70 MHz |
| D04G02 | +1.019 dB / +30 MHz | -1.100 dB / -110 MHz |
| D12G05 | +1.148 dB / +10 MHz | -1.051 dB / -110 MHz |

在这三个局部点，增加Ls1令峰差向正方向移动，增加Lm令峰差向负方向移动；Lm对中央谷更敏感。可以用Ls1与Lm的二维局部灵敏度联合修正等峰和中心。灵敏度幅值随宽度变化，不能把一个配置的矩阵固定套给所有配置。中央谷按10 MHz输出网格定位，上表中心变化存在采样分辨率限制；探针为同数值政策、分别自适应后的局部有限差分。

## 6. P/R目前能说到哪里

本批导出中的P_response由S11双峰水平反推，R_BW由带宽反解。R_BW和BW之间的漂亮关系包含定义上的循环，不能当作阻抗到带宽的独立规律。当前回归没有使用它们。

要验证与均匀模型同含义的P=(Zm/50)(Zs/50)、R=Zm/Zs，需先独立提取与当前εr=3.55、h=0.813 mm一致的微带和槽线阻抗，再分析折臂与间隔引入的修正。工作区旧TXLINE校准为εr=3.38，不应直接用它给当前24项贴“物理P/R”标签。端口模态阻抗也不能未经定义就当作内部槽线特性阻抗。

当前最实用的设计顺序是：用Wm/Ws选带宽范围与反射水平，再用Ls1/Lm联合调等峰和中央谷，最后评估折臂及间隔对损耗和体积的影响。
