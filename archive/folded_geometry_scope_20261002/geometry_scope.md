## 1. 结构和尺寸定义

论文 Fig. 8 的虚线折回部分是公共地平面上的槽线，橙色部分才是微带线。当前建模脚本把主槽放在全局 X 方向，与论文画面方向不同，以下只按尺寸定义判断。

![论文 Fig. 8](paper_fig08.png)

根据当前 `folded_slot_rectangles()` 的矩形构造，定义：

- 平行槽段之间的净金属间隔：`g = Ls2 - 2*Ws`。
- 单侧折回直段的净长：`a = Ls3 - Ws`。此量不包括拐角占据的宽度，不等同于完整电长度。
- 两个相向折臂端部之间的净开口：`m = Ls1 - 2*Ls3`。
- 折臂端部到中央微带条边缘的平面投影余量：`c = (m - Wm)/2`。这是避免折臂进入中央微带区域的研究约束；微带和地平面分层，投影重叠本身不等于金属短路。
- 几何折回占比：`rho = 2*Ls3/Ls1`。它只描述矩形布局，不是电长度比例或耦合强度。

## 3. 当前单过渡器的研究窗口

| 条件 | 本阶段采用的值 | 用途 |
|---|---|---|
| 平行槽净间隔 g | 0.35–0.75 mm | 包含论文两例及 B0，排除几乎贴合的布局 |
| 单侧折臂净长 a | 1.40–2.30 mm | 围绕论文约 1.9 mm 和 B0 约 1.8 mm 扫描，保留已有 F2、F3 |
| 折回占比 rho | 不超过 0.50 | 要求中央开口 m 至少为 Ls1 的一半，限制过度折回 |
| 折臂到中央微带投影余量 c | 至少 h，即 0.813 mm | 当 Wm 随阻抗目标变化时，仍保留中央区域 |
| Wm、Ws | 由配对均匀模型及目标阻抗确定 | 改变宽度后必须重算 g、a、m、c，不能沿用旧间距 |
| Lm、Ls1 | 作为相位和中心频率调节量 | 每次修改后重新应用几何筛选条件 |

上述条件必须同时成立，不是可以任意组合的独立参数盒。可直接写成：

```text
0.35 <= Ls2 - 2*Ws <= 0.75
1.40 <= Ls3 - Ws <= 2.30
Ls1 >= max(4*Ls3, 2*Ls3 + Wm + 2*h)
```

所有原始尺寸还必须为正。当前 Ws=0.437335 mm 时，前两个区间对应 `Ls2=1.224670–1.624670 mm`、`Ls3=1.837335–2.737335 mm`，但仍受最后一个联合条件约束。

这组条件的几何充分性：`g>=0.35>0` 保证主槽与平行折回段保留金属间隔；`Ls1>=4*Ls3` 保证两个折臂之间的开口 `m>=Ls1/2>0`；第二个 Ls1 下界保证 `c>=h>0`。因此，在当前对称矩形拓扑中，两个相向折臂不会相碰，折臂和端部连接段的投影也不会侵入中央宽度 Wm 的条带。它不限制设计中本来就需要的微带—主槽投影交叉。

例：保持 B0 的几何路径、取 g=0.75 mm、a=2.30 mm 时，几何补偿所得 Ls1=10.165990 mm，而占比约束要求 Ls1>=10.949340 mm。该组合必须被筛掉，不能因为两个单变量都在范围内就直接求解。

同一导体层上本来不应连接的微带金属，另检查真实边缘距离，当前研究至少保留 0.35 mm；不同层上的投影交叉按原拓扑保留。此项需要从实际 CAD 实体检查，不能用上述槽线公式代替。
