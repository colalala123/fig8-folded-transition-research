## 模型结果及限制

训练内验证选择了二次岭回归，不根据留出集表现临时换成MLP。选中模型的留出误差：Lm MAE0.015138mm/P95 0.044606mm；Ls1 MAE0.050189mm/P95 0.130437mm。

原LBFGS共享MLP在部分训练折发生10条异常终止警告，原结果和警告均保留，不能称优化过程完全稳定。`mlp_optimizer_check.py`改用Adam，**只在40条训练数据的分组折内**诊断，未重用留出集选模型；Adam零收敛警告，但训练内综合误差仍未优于二次岭回归。因此现部署继续选简单模型，不宣称神经网络已经胜出。

当前学习的是Lm/Ls1两项长度修正，Wm/Ws由理论P/R映射确定；并非均匀模型四个自由修正量的同任务同规模比较。12条留出结果也不能代表1000条数据的精度稳定性。现有全曲线代理未显式建模长度扰动，新学习长度的响应估计只是原已调谐长度附近的近似，必须进入HFSS验证。
