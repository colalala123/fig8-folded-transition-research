# Fig. 8 执行交接包

给其他执行 agent 的入口：先复制 `交给执行agent.txt` 的全部内容，再让它阅读 `执行方案.md`。

该包面向同一台 Windows 工作站、同一工作目录。压缩包不包含 AEDT 软件、许可证、原始工程或完整历史结果；换机器时需先迁移并复核依赖，不可只解压后假定能求解。

| 文件 | 用途 |
|---|---|
| `执行方案.md` | 研究目标、已知结论修正、端口协议、收集器验证、相位算法、验收、阶段门、留出验证 |
| `交给执行agent.txt` | 可直接复制的首阶段任务消息 |
| `candidate_matrix.csv` | 120 个候选初值，全部未仿真 |
| `pilot_24.csv` | 默认执行的首批 24 行 |
| `holdout_24.csv` | 模型冻结后才执行的独立留出 24 行 |
| `prepare_package.py` | 离线生成并检查矩阵和本机依赖，不启动 HFSS |
| `preflight.json` | 矩阵计数、几何检查、宽度秩、依赖及哈希 |
| `audit_response_models.py` | 对已保存曲线做公平三参数/四参数拟合 |
| `fair_model_audit.json` | 已完成的离线公平拟合结果 |
| `result_schema.json` | 迭代表、合格表、失败表的字段与状态约定 |

本轮只创建交接包并运行离线检查，没有启动新增 HFSS 求解，没有向其他聊天或 agent 发送任务。

120 个配置是研究候选，不是保证 120 个合格解。默认只执行准备、数值协议检查和首批 24 点；扩展和留出按方案阶段门推进。新批量求解器尚待执行 agent 按接口实现并先做基准验证，包内工具不冒充现成的完整 HFSS 自动调参器。
