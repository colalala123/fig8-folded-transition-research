# Fig8 弯折模型规律与设计方法

更新日期：2026年10月26日。当前34个弯折配置已经能够支持限定范围内的经验设计方法：**宽度组合决定主要带宽水平，也提供匹配取舍；折臂对已调谐设计的带宽影响较小；长度用于校正中央谷和等峰条件。** 这里得到的是经新点验证的几何尺寸关系，不是已经证明的物理阻抗P/R定律。

- **主带宽 BW**：S21≥−2 dB的连续通带宽度，单位GHz。
- **联合带宽**：同时满足S11≤−10 dB和S21≥−2 dB的通带宽度。
- **内峰匹配**：S11带内两个局部峰的高度；数值越负，峰处匹配越好。平均值按线性幅值平均后转dB，同时查看较差的那个峰。
- **中央谷**：中间S11谷，目标6.72±0.03 GHz，不等同于通带两边的算术中点。

## 2 规律一 两种宽度增大都使主带宽增大

对原24项，在相同槽宽和折臂等级下，微带宽度Wm增加的18次相邻比较全部增宽；相同微带宽度和折臂等级下，槽宽Ws增加的16次相邻比较也全部增宽。比较对象均经过长度调谐，不是其余全部尺寸固定的单变量实验。

冻结的局部经验式为：

```text
BW/GHz ≈ 6.804574332
         + 0.798166452 ln(Wm / 1.20 mm)
         + 0.866177522 ln(Ws / 0.44 mm)
```

ln为自然对数。式中没有折臂项，是因为原数据中加入简单折臂项对分组验证的改善很小，且在约10万网格子集上不稳定；不意味着折臂完全无作用。

|验证方式|平均绝对误差 MHz|均方根误差 MHz|最大绝对误差 MHz|
|---|---:|---:|---:|
|原24项留整组宽度交叉验证|22.9|29.7|60.1|
|新增6项|10.704|13.005|23.489|
|新增4项|9.925|10.588|14.497|
|新增10项合计|10.392|12.096|23.489|

若改用新增10项的同网格直接频点带边核验值，平均误差为10.352 MHz，最大23.620 MHz，结论不变。新增点误差较小不能解读为未来任何点都保证小于24 MHz；原24项整Wm水平留出最大误差约79 MHz，且新点尚未覆盖所有边界情况。

**可用结论：先用宽度公式估计带宽和反算尺寸，再检查实际曲线；不必靠大批盲扫才找到起点。**

## 3 规律二 相近带宽下 宽微带与窄槽线改善内峰匹配

保持公式预测带宽不变，可推导：

```text
Ws₂ / Ws₁ ≈ (Wm₂ / Wm₁)^(-0.92148)
```

这是经验式的代数推导。其设计含义是：增大微带宽度时，减小槽宽，可近似维持主带宽。新4点与已完成的中间宽度组合共同验证了这个方向。

以下为a=1.8 mm、g=0.55 mm的实际例子。主带宽与内峰使用直接频点核验值，联合带宽沿用完整插值曲线：

|Wm mm|Ws mm|主带宽 GHz|两内峰平均S11 dB|联合带宽 GHz|
|---:|---:|---:|---:|---:|
|1.25|0.543938|7.034845|−13.592|6.855707|
|1.40|0.490000|7.044460|−15.138|6.847873|
|1.90|0.369815|7.012561|−20.764|6.682819|

三个主带宽仅相差31.90 MHz，而首尾内峰平均S11改善7.17 dB。a=1.4 mm也重复出现同方向结果：主带宽跨度20.56 MHz，匹配改善6.95 dB；两种折臂下平均峰和较差峰都逐级改善。

**但是，内峰更低不等于全通带更宽。** 上表首尾联合带宽缩小172.89 MHz；短臂组缩小116.10 MHz。内峰高度不能决定两端阈值交点，因此不应只看S11内峰就宣称整体带宽改善。

设计取舍是：优先压低内峰时，可沿宽微带、窄槽线方向选型；优先扩大联合带宽时，必须同时检查两条曲线和带边，不能只追求内峰最深。

## 4 规律三 折臂改变后的带宽小变与匹配改善

在同一宽度组合下，a由1.4增至1.8 mm，并分别确定满足中央谷和峰差要求的Lm、Ls1。新增5对的直接核验结果为：

|Wm mm|Ws mm|主带宽变化 MHz|内峰平均S11变化 dB|
|---:|---:|---:|---:|
|1.05|0.35|+12.806|−0.304|
|1.40|0.49|+15.000|−0.288|
|1.85|0.53|+18.231|−0.513|
|1.25|0.543938|+20.018|−0.258|
|1.90|0.369815|+3.663|−0.482|

新增5对都表现为主带宽小幅增加、内峰降低。原12对内峰也全部降低；原主带宽则10对增加、2对减小，不能说全部34项都证明“加长折臂必然增宽”。最小的3.66 MHz差异尤其不宜放大解释。

**目前适当的表述是：在这两个折臂水平的调谐设计中，主带宽变化相对较小，内峰匹配改善方向更一致。** 不能据此给出任意折臂长度的连续公式，或把匹配改善全部归因于辐射损耗。

导师所述“弯折减小辐射边缘损耗，并可能略减本征带宽”没有被本数据否定：这里没有直槽对照，且比较的是两种弯折结构在长度调整后的S参数阈值带宽，不是单独的本征带宽或辐射损耗。

## 5 规律四 长度补偿不能只保持几何路径

当折臂增加0.4 mm时，新增5对通过设计的Ls1减少0.617–0.664 mm，Lm减少0.0256–0.0340 mm。与原12对的平均补偿约−0.646 mm、−0.033 mm一致。

因此可以把 **Ls1减约0.65 mm、Lm减约0.03 mm** 用作从短臂迁移到长臂的局部起点，有邻近合格数据时优先对Lm/Ls1插值。简单保持几何总路径会要求Ls1减少0.80 mm，与实际合格长度不同，不能替代电磁调谐。

原有三个局部探针支持以下调参方向，峰差定义为“低频内峰dB减高频内峰dB”：

- 增加Lm：中央谷下移，峰差向负方向移动。
- 增加Ls1：峰差向正方向移动；中央谷也会变化，幅度较小且依配置而异。
- Lm和Ls1需要联合调整，不能当作完全互不影响的两个旋钮。

新增10项使用邻近合格长度插值后全部初值达标，无额外几何调参；这验证了局部初值迁移的实用性，但不保证任意新点都一次成功。

## 6 可复用设计步骤与边界

1. **先明确指标。** 主公式预测的是−2 dB主带宽，不能直接拿来保证联合带宽。
2. **由目标带宽选宽度组合。** 给定Wm后反算：

```text
Ws = 0.44 mm × exp{[BW/GHz − 6.804574332
                   − 0.798166452 ln(Wm/1.20 mm)] / 0.866177522}
```

3. **结合匹配需求选型。** 同一目标带宽通常有多种搭配；改善内峰可优先考虑更宽Wm、更窄Ws，同时保留联合带宽检查。
4. **选已验证折臂并取长度初值。** 在同折臂相邻合格网格中插值Lm/Ls1。由定义设置Ls2=g+2Ws、Ls3=a+Ws，避免改槽宽时漏改几何约束；检查实体间距和非预期连接。
5. **按原中心和峰差条件检查。** 中央谷6.72±0.03 GHz、两内峰差≤0.5 dB，并查看S11/S21与通带边缘。只为原设计条件调长度，不为贴合带宽预测反向调宽度。
6. **报告实际误差。** 保留主带宽、联合带宽、两峰及较差峰、真实网格和调参记录。现有34项无需为此次整理重新求解。

适用条件：εr=3.55、tanδ=0.0027、h=0.813 mm；Wm=0.90–2.00 mm、Ws=0.30–0.58 mm；g=0.55 mm；已验证a=1.4或1.8 mm；采用现有Fig8拓扑、端口与中央谷/等峰条件。这是范围内稀疏样本支持的经验方法，不是每个范围内尺寸都已仿真过。

原24项含8项超过11.2万单元的历史结果，不能说34项全都采用统一网格。原16项约10万网格子集得到的系数相近；新增10项网格为100001–104261。直接频点核验支持插值精度，不是跨网格收敛证明，也不能仅凭网格数相近认定误差完全相同。

**尚不能宣称的结论：** 跨材料/跨间隔通用关系；连续折臂定律；独立物理P/R到带宽的关系；弯折减辐射的定量机理。用带宽反算R再拟合带宽会产生循环，不能当独立证据。S参数剩余功率也不能直接全部叫作辐射损耗。

### 可用于汇报的结论

在固定材料、净间隔及中心与等峰调谐条件下，Fig8弯折过渡结构的−2 dB带宽可由微带宽度和槽宽的对数经验式预测。该式由24项建立，在后续10项未参与拟合的配置上得到10.39 MHz平均绝对误差和23.49 MHz最大绝对误差。等预测带宽设计验证表明，增大微带宽度并减小槽宽可在主带宽近似不变时显著改善S11内峰，但联合匹配带宽存在缩小的取舍。折臂从1.4增至1.8 mm时，经长度补偿后的主带宽变化较小，内峰改善方向较一致。上述结论构成局部几何设计方法，尚不构成辐射机理或物理P/R定律的证明。
