# 脱敏配置模板

这些文件是新建的占位模板，**没有复制真实令牌、密码、私钥、许可证服务器、聊天ID或本机IPC管道**。不修改原工程，不自动开启HFSS或hook。

|文件|用途与边界|
|---|---|
|paths.example.json|本机路径填写清单；占位符不自动展开|
|hfss-run.example.json|最新单例设置参考；并非现有runner可直接导入的配置协议|
|completion-hook.example.json|通用hook1.1.0的配置结构；授权列表故意为空，直接加载会拒绝发送|
|completion-heartbeat.policy.example.json|后期5分钟完成后心跳的策略说明；不是1.1.0可直接消费的配置|

## 新电脑填写

1. 路径、HFSS安装和许可由新电脑自行配置。不要复制旧机器PID、进程创建时间、工程锁、事件发件箱或已授权聊天列表。
2. 对hook先按 `../tools/completion-hook-1.1.0/INSTALL_FOR_AI.md` 操作。用户明确授权当前目标后，用工具的 `init --authorize-current-thread` 生成本机 `.local/config.json`，再运行只读doctor检查。不要把本模板中的空授权列表当作发送许可。
3. 真实配置仅放在被Git忽略的 `.local/` 或仓库外。不把GitHub令牌、OpenAI密钥、密码、私钥或许可证服务地址写进提交；离线预测不需要这些凭据。
4. 归档中的整批暂停和单例关闭不因填写模板失效。仿真、消息投递和新电脑测试都需另行明确授权。

## 公开范围

仓库按所有者要求临时公开12小时，然后由预约任务尝试恢复私有。临时公开不授予开源许可，也不能收回公开期间被下载或复制的内容。恢复任务依赖本机调度与GitHub连接可用；凭据始终不应进入公开库。
