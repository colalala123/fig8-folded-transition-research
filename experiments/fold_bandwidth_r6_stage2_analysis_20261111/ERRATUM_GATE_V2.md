# 只读汇总的直槽元数据修正

在阶段2a继续求解期间，离线复核发现首版汇总器只识别了`straight`，而实际直槽拓扑名称是`straight_control`。因此旧汇总快照里E0的派生a/g被误算成负值。**HFSS输入、原生槽盒、求解结果、提取与数值审核均未受影响，未重算任何几何。**

修正在新文件`gate_v2.py`中：两种直槽标记都给出a=0、g=null（直槽没有折叠间隔），未知拓扑拒绝。旧脚本和已发布快照保留，不覆盖；后续完整批次汇总使用V2。10项离线回归测试通过，新增两项专门检查直槽名称和未知拓扑。

影响核查：E0在首版中已经由拓扑字段明确排除在E1/E2阶梯之外，且本身未调准。因此E1的6个、E2的5个有效阶梯位置以及已发布图表和BW数值均不变。当前新快照是`snapshots/after_E2_v2.json`；旧`E2_summary/SNAPSHOT.json`中的E0派生a/g字段应以本修正为准，不能用于几何解释。

此修正不接触冻结执行器、不修改授权、不增加Analyze，也不产生新的2b释放。
