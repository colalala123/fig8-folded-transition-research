## 从实际构造坐标得到的约定

以顶层槽为例（底层有相同 XY 轮廓）：

| 元件 | x 起点 | y 起点 | x 尺寸 | y 尺寸 |
|---|---|---|---|---|
| 主槽 | `-Ls1/2` | `-Ws/2` | `Ls1` | `Ws` |
| 右连接段 | `Ls1/2-Ws` | `-Ls2+Ws/2` | `Ws` | `Ls2-Ws` |
| 右折臂 | `Ls1/2-Ls3` | `-Ls2+Ws/2` | `Ls3-Ws = a` | `Ws` |
| 左连接段 | `-Ls1/2` | 同右侧 | `Ws` | `Ls2-Ws` |
| 左折臂 | `-Ls1/2+Ws` | 同右侧 | `a` | `Ws` |

所以：

- **Ls2、Ls3 不是两段独立的中心线长度。** Ls2 是主槽最上沿到折臂最下沿的总外沿距离；Ls3 是一侧外沿到该折臂内端头的总水平距离（含连接段宽度）。
- 两个折臂均在主槽的 **−y 侧**，左右两端都向 **x=0** 折回；不是一个朝 +y、另一个朝 −y。
- 平行槽净间隔 `g = Ls2 - 2Ws`；主槽与折臂中心线间距 `Ls2-Ws = g+Ws`。
- 折臂端头间的 x 投影净距 `Ls1-2Ls3`。
- 到中央微带边缘的 x 投影净距 `(Ls1-2Ls3-Wm)/2`。微带在不同 z 层，不能把投影间距直接称为三维导体间最短距离。
- 本次暂沿用旧预测器的保守投影间距下限 **0.813 mm**，这不是已确认的加工极限。

INV01 例：主槽 Ls1≈12.6199947、Ws≈0.345967019；连接盒 y 长≈0.895967019；折臂盒 x 长=1.4。
端头间距≈9.12806066 mm，端头到微带的 x 净距≈3.60722024 mm。

## 关键修正：参数长度和不等于几何中心线路径

原计划/历史模型的变量：

```
L_parameter_sum = Ls1 + 2Ls2 + 2Ls3
```

沿折臂开口端到另一开口端、拐角取正交中心线交点的几何折线路径：

```
L_center = (Ls1-Ws) + 2(Ls2-Ws) + 2(Ls3-Ws/2)
         = L_parameter_sum - 4Ws
```

这个中心线只是几何定义，**也不是严格电长度**。INV01 中两者约为18.595797和17.211929 mm。

80条数据原来的 `半波长-L_parameter_sum` 均值为 **−1.593545 mm**；换成上述几何中心线后，
`半波长-L_center` 均值为 **−0.089758 mm**，范围 **−0.270951～+0.111364 mm**。
因此，不能把原来的“长约1.6mm”直接解释为折叠电长度打折，也不能直接与均匀模型的长度偏差比较。

**不改写历史模型或原始数据。** `chain.py` 继续用原参数长度和及配套修正系数；
若未来改用中心线，须同步令 `ΔLs_center=ΔLs_parameter_sum+4Ws`，否则会重复扣/补长度。
原计划 `rho` 也只是参数长度和定义的比值，本次仍按该原判据筛选，另存中心线长度，未擅自换判据。
