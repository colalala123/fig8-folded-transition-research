# 新实验目录与记录规则（仅方案，未授权运行）

建议未来新建独立批目录，不使用旧24/48点的运行路径、队列、预算或 IPC：

```
<new-batch>/
  authorization.json             # 用户明确授权、有限预算、目标聊天
  model_freeze/<revision>/       # 预测和模型哈希，先冻结后求解
  runs/<design_id>/attempt_001/   # 弯折点；每次技术/调参尝试独立目录
    RUN_RECORD.json
    input/                       # 六尺寸、原材料、设置、工程校验摘要
    native/                      # 原生复数、多模式/端口证据、日志
    result/                      # 提取、带宽、设计评分
    evidence/                    # mesh、真实核数、实际看图 ACK
    hook/                        # 不可变终态事件、持久化去重投递记录
  uniform_control/<design_id>/attempt_001/  # 直槽对照不并入弯折训练
```

`RUN_RECORD_SCHEMA.json` 是 Draft 2020-12 的结构契约，测试使用 jsonschema 4.26.0。
结构校验不是求解授权、数值验收或 ACK 的替代品。真正运行器还必须做下列跨字段/文件校验：

- 先核对授权目标、预算和暂停；`Analyze_requested <= Analyze_limit`；数值为真实请求数，不把网格轮数当请求数。
- 预测文件及模型哈希匹配，冻结时间早于首次请求；几何与实际工程一致。
- 请求14核/1任务/1组、串行；真实进程证据确认，不能把请求配置当作观察值。
- 保留每次请求的结果和失败证据，不伪造成功、覆盖失败或清工程锁。
- 曲线必须原生复数、频率严格递增；哈希匹配；带宽存低/高边、连通分量数和截断状态，缺失用 null。
- 使用原门限：主窗3.92–9.52GHz、S11≤−20、S21≥−2、三谷、中心6.72±0.03、内峰差≤0.5；
  等纹波对比额外记录−21±0.15目标，不替换主窗要求。
- 数值策略待阶段1确认：目标10–11万，≤11.2万标记轻微超限，MaxDeltaS=0.005；同时检查新基准的响应差异。
- `solve_completed`、`numerical_pass`、`design_pass` 三者独立；未完成检查为 null，不能默认 true。
- 结果级别默认名义插值；没有直接频点、公差验证就不写成认证。
- 多模问题：原端口每口两模式。`1-|S11|²-|S21|²` 只是基模未计功率，还可能包含模式转换；
  无耗对照不能自动把它全部叫辐射，须补全部出射模式归一化功率或可靠辐射边界积分及功率闭合。
- 前瞻点失败也永久保留 `prospective_test` 原身份；以后纳入训练须在新模型版本明确记录数据用途变更，
  不能回改原评分/身份并继续声称是独立盲测。
- 完成hook仅投递给新批明确授权的聊天；终态→原生导出→不可变事件→去重投递→独立核验→实际看图ACK。
  5分钟心跳只用于完成消息已发送、却没有新仿真时；正常仿真不周期唤醒。本阶段没有挂hook或发送消息。

## 规模与停止条件

- 阶段1候选12次：3基准重跑+9个槽宽扰动，其中0扰动是独立重复，不与基准合并。
  两次相同中间基准可作初步重复性检查，**仅两次不足以精确估计噪声分布**；扰动二次残差混合模型误差，不能直接等同数值噪声。
- 阶段2原37设计最多3次/设计，所以硬上限是111次设计尝试，计划中的约75只是预估。
- 阶段3最多30次有耗调谐+10次对应最终几何的无耗对照=40次；无耗点在父项调准后才冻结真实几何。
- 阶段4原拟8次，仅一次/点，不当场调参。本次有1个预留点未过rho，不能直接宣称已有8个可行点。
- 阶段1–4原始上限171次设计尝试；排除当前5点后158次；这都**不是Analyze次数授权**。
  每次设计尝试的自适应/扫频请求数尚需有限预算，不能默认为机时无限或借用旧2236额度。
- 任一阶段的门槛失败停下报告；不以“全达标”为理由扩范围、补无穷次求解或修改验收。

先只授权阶段1的三基准，监督通过后再决定扰动及后续阶梯。本文不构成启动指令。
