# 阶段3调参长度换算缺陷及接续约束

发现于2026-11-13日本时间。原阶段3执行代码和输入均保留，不覆盖。

## 确认的程序问题
R2中心线定义：
L_c = Ls1 + 2Ls2 + 2Ls3 − 4Ws
而 Ls2=2Ws+g、Ls3=a+Ws，因此：
L_c = Ls1 + 2a + 2g + 2Ws。
新阶段3调参器反解Ls1时错误使用2a+2g+4Ws，多扣了2Ws。这是本执行者实现错误，不是HFSS数值失败或物理规律。

## 影响范围
- 阶段1/2及其冻结数据、模型均不受影响。
- 阶段3所有原R3初值不受影响。
- N04直槽三次几何不受此弯折分支错误影响，仍保持未调准结论。
- 首个弯折N04/a=.6的T1不受影响。
- 受影响的T2参数已派发，保留真实几何和成本；只让正在运行的原生Analyze返回，随后按已写STOP禁止新增请求，不杀正在运行的HFSS。不得宣称该点数值通过、不得用它推断物理规律。
