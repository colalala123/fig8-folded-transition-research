# R6 阶段2离线准备（尚未释放仿真）

已完成纯离线的2a准备器、冷启动执行器、分段核验、双账本、长度调准、独立提取及单点派发代码。尚未创建阶段2运行目录、未启动阶段2 HFSS、未提交阶段2 Analyze；1b的9点数据和进入条件仍必须先收齐、形成报告并推送。

## 执行边界

- 2a严格使用R1冻结的N14十五项，初始槽盒逐项对照R1表；每设计至多3个几何、全批45、全计划187。每个冷启动几何至多14个实际Analyze（16轮起步、最多12次单轮续算、最后一次扫频），双计数不混淆。
- 调准口径是中央谷6.72±0.03GHz、内峰差≤0.5dB，不能误用−20dB硬指标作为固定宽度实验的调准条件。
- 长度更新严格使用原计划fm*=6.622GHz、fs*=6.588GHz及四分之一/半波长修正，再取整0.001mm。
- Wm/Ws/Ls2固定；只有R2允许的、调长后净间距不合格时折臂缩短规则可以改变实际a，必须记录实际a。
- 直槽在本研究新的uniform_control子目录建副本，不触碰原均匀模型数据。API替身测试不是HFSS实机证据。真实建模后仍须原生槽盒对照、两端口两模式回读，再允许Analyze。
- 冷启动执行器由已运行的R6 v2派生；每点独立后台Python及独立AEDT/TEMP/TMP，外部仅读文件/进程。请求14核1任务，真实自适应14核1组，最后扫频合法角色1组且≤14核并保持全部网格历史不变。
- 不唯一的电路提取不能用于盲目长度修正；保留诊断并标记，不追加任意求解。长度调准和拟合可辨识性分开记录。
- 没有自动全批调度器、hook或定时消息。每点需独立提取、实际看图ACK后才决策；每批及每10个完成Analyze按R4推送。
- 此版本不直接处理跨进程缓存恢复。技术异常先保留证据并停止，随后依据R6 2.3独立核验、版本化修复，不能用冷启动入口假装缓存恢复或删掉旧marker。
- 本目录尚不负责2a完成后的κ拟合/2b重新冻结及2b释放。这些属于下一进入门槛，不因本目录编译通过而视为已完成。
