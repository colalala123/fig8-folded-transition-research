# R6 阶段2离线准备（尚未释放仿真）

本目录目前只有纯离线的长度修正、直槽新副本构建器和模拟API测试。没有创建阶段2运行目录、没有启动阶段2 HFSS、没有提交Analyze；1b的9点数据和进入条件仍必须先收齐。

- 调准口径是中央谷6.72±0.03GHz、内峰差≤0.5dB，不能误用−20dB硬指标作为固定宽度实验的调准条件。
- 长度更新严格使用原计划的fm*=6.622GHz、fs*=6.588GHz及四分之一/半波长修正，再取整0.001mm。
- 调宽度没有被引入；只有R2允许的、调长后净间距不合格时折臂缩短规则可以改变实际a，必须记录实际a。
- 直槽在本研究的新uniform_control子目录建副本，不触碰原均匀模型数据。
- 此处API替身测试不是HFSS实机证据。真实建模后仍须回读原生槽盒、核验两端口两模式、冻结当次预测，再允许Analyze。
- 不唯一的电路提取不能用于盲目长度修正；保留诊断并标记未调准，不擅自追加求解。

完整的阶段2授权冻结、预算执行器、技术恢复与批次门槛尚未在此目录交付，不能仅凭这些函数派发仿真。
